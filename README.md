# Hotel Mahadev - Sindhari, Barmer

The official website for **Hotel Mahadev**, a premium, pure vegetarian highway hotel and restaurant located on RJ SH 28 (Sanchore Road), opposite Subhash College, Sindhari, Barmer, Rajasthan.

## About
Hotel Mahadev is a trusted highway stop for families, tourist buses, and commercial travelers, offering authentic Marwari hospitality, high-speed pure vegetarian dining, and secure deluxe AC accommodation.

## Key Features
- **24/7 Pure Vegetarian Dining:** Freshly prepared Marwari and Kathiyawadi cuisine (Dal Baati Churma, Sev Tamatar).
- **Secure Highway Parking:** Multi-acre campus with massive parking for 50-seater buses and trailers.
- **AC Guest Rooms:** Deluxe, comfortable air-conditioned accommodation with power backup.
- **Family Comfort:** Dedicated quiet family AC dining hall, sanitary western washrooms, and 24/7 professional management.

## Technical Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express
- **Build Tool:** Vite
- **AI Integration:** Google Gemini API (for AI review assistant)

## Local Development
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set your environment variables in `.env` (create from `.env.example`).
4. Run locally:
   ```bash
   npm run dev
   ```
